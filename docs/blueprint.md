# **App Name**: Oracle's Wisdom

## Core Features:

- Buffett Principles: Interactive Warren Buffett Principles: Expandable cards reveal principles with kid-friendly explanations, real-world examples, and Buffett quotes.
- Munger's Models: Charlie Munger's Mental Models: Interactive section that shows the key concepts with animated explanations and examples kids can relate to.
- Calculator: Animated calculators: a tool showing Compound Interest which demonstrates growing money and offers fun icons and animations to show real-time calculation updates.
- Investment Game: A dynamic page of "What Would Buffett Buy?" for an interactive experience.
- Portfolio Tracker: Includes the Berkshire Hathaway Portfolio Tracker with top holdings and company logos in the list.
- Sidebar Toggle: Menu button labeled MENU toggles transparent sidebar sliding on/off-screen, available on the main page and sidebar.
- External Links: Links to Future Ready Hub, Dr. Recommends, Etsy shop, Discoveries portal, and Own Your Day page.

## Style Guidelines:

- Primary color: Deep Blue (#003366) to convey trust, wisdom, and financial stability; represents Berkshire Hathaway's solid reputation.
- Background color: Very Light Blue (#E0F7FA) to provide a calming, trustworthy feel; supports readability while subtly connecting to the primary theme.
- Accent color: Gold (#FFD700) as an analogous color to represent wealth and the 'Oracle' theme, providing contrast to deep blue for CTAs.
- Font pairing: 'Space Grotesk' (sans-serif) for titles and headings, matched with 'Inter' (sans-serif) for body text.
- Code font: 'Source Code Pro' for display of code snippets in any sections relating to software.
- Mobile-first, center-justified layout ensures optimal cell phone viewing; key elements such as titles, sections, links and sidebars should render well in compact width; links in the sidebar and footer should shine or glitter on hover, using CSS animation for the effect.
- Background animation in night mode: Dark blue/black background with twinkling stars using CSS keyframes; add shooting star animations periodically to capture visitor engagement
- Background animation in day mode: Light blue background with drifting white clouds and birds flying; parallax scrolling and hover effects to show additional feedback and context.
